# Domain Context: RepoPulse

## Terms

### Tracked Repository
A public GitHub repository (identified by its owner and name) registered within RepoPulse for tracking and issue synchronization.

### GitHub Issue
An issue belonging to a Tracked Repository fetched from GitHub's API. Note: Pull requests are explicitly excluded from being classified or stored as GitHub Issues in RepoPulse.

### Issue Labels
A JSON array of string names (e.g. `["good-first-issue", "bug"]`) representing the categories or tags attached to a GitHub Issue.
